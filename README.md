## 🚀 Overview

TaskFlow is a modern, collaborative task management system built with Laravel and React. It features real-time updates, role-based access control, and a beautiful Kanban board interface.

## ✨ Features

- 🔐 Authentication & Authorization (JWT)
- 👥 Team & Project Management
- 📊 Kanban Board with Drag & Drop
- 🔔 Real-time Notifications
- 📱 Fully Responsive Design
- 🐳 Docker Support
- 🧪 Unit & Integration Tests

## 🛠️ Tech Stack

**Backend:**
- Laravel 11
- MySQL 8.0
- Redis
- JWT Authentication

**Frontend:**
- React 18
- Tailwind CSS
- Axios
- React Query

**DevOps:**
- Docker & Docker Compose
- Nginx

## 📦 Installation

### Prerequisites
- Docker & Docker Compose
- Git

### Quick Start
```bash
# Clone repository
git clone https://github.com/yourusername/taskflow-project.git
cd taskflow-project

# Start with Docker
docker-compose up -d

# Access application
# Frontend: http://localhost:3000
# Backend API: http://localhost:8000
```
